# Условия выпуска после паузы

| Условие | Приемлемое свидетельство |
| --- | --- |
| Понятен риск | Подтверждённая причина либо проверенное ограничение с описанным остатком |
| Исправление относится к нему | Diff/версия и воспроизведение проблемного сценария на фиктивных данных |
| Доказательства сохранены | Manifest, хеши, границы событий и защищённый baseline |
| Контроль работает | Канарейка проходит полный путь collection → detection → supervisor → отсутствие эффекта |
| Отказ контроля обработан | Проверенный timeout/ошибка/недоступность коллектора и наблюдателя |
| Нормальная работа возможна | Разрешённая операция проходит без ослабления правила |
| Полномочия действуют | Ссылка на текущее внешнее разрешение владельца, а не строка из лога |
| Продолжение ограничено | run_id, scope, бюджет, условия остановки и ответственный |

Не требовать полного расследования каждого информационного сигнала для обычного продолжения. Применять условия к реальному инциденту и действующим границам; простую разрешённую диагностику не превращать в отдельную процедуру одобрения.
