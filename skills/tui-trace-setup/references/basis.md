# Основания и границы подхода

Пакет — практический протокол контроля, не продукт OpenAI/Anthropic и не аттестация безопасности. История из запроса используется как мотивация; пакет не подтверждает подробности этого инцидента. Проверка источников: 2026-09-13.

- [Anthropic, Reasoning models don't always say what they think](https://www.anthropic.com/research/reasoning-models-dont-say-think), 2025-04-03. Эксперименты показывают ограничения достоверности видимого reasoning. Вывод для пакета: сопоставлять текст с действиями и независимыми результатами; отсутствие признания не доказывает отсутствие нарушения.
- [Claude Code, Hooks reference](https://code.claude.com/docs/en/hooks). Документация различает обработку до и после вызова инструмента; PreToolUse может блокировать вызов. Вывод для пакета: чтение уже сохранённого журнала не заменяет блокировку до исполнения. Обёртку необходимо отдельно проверить с используемой версией, включая timeout, ошибку и неизвестный exit code. Готовая обёртка Claude Code в пакет не входит.
- [OpenTelemetry, URL attributes](https://opentelemetry.io/docs/specs/semconv/registry/attributes/url/). URL могут содержать учётные данные и чувствительные query-параметры. Вывод для пакета: отчёт ограничивать метаданными и проверять редактирование URL до публикации.

JSONL-схема и пороги в этом пакете — собственные проектные решения, а не совместимость со стандартом OpenTelemetry. Нет универсального адаптера для всех TUI, классификатора любых атак, хранилища WORM или готового системного supervisor.
