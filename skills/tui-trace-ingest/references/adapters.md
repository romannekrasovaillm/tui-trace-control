# Карта адаптации

| Источник | Что извлекать | Ограничение |
| --- | --- | --- |
| Нормализованный JSONL v1 пакета | Все поля схемы, source_ref, связь вызов/результат | Проверить происхождение и непрерывность до доверия метаданным |
| Нативный JSONL/JSON TUI | Документированные envelopes, роли, tool IDs, результаты, события сессии | Имена полей, каталоги и формат зависят от версии; готового vendor-адаптера нет |
| Экспорт диалога/Markdown | Явные роли, цитаты, видимые сообщения и отметки инструментов | Не доказывает полный список инструментов или успешность команд |
| stdout/stderr, tty transcript | Наблюдаемый вывод, exit status только при достоверной привязке | ANSI, перерисовка экрана, буферизация и обрезка; не угадывать скрытые вызовы |
| Runner/hook/OS audit | До/после вызова, фактический путь, сетевой адресат, процесс | Должны быть защищены от worker; hook после действия не предотвращает эффект |

Для каждого адаптера хранить: имя/версию, входной формат, поле run/agent, правила seq и correlation, отображение событий, redaction, неизвестные поля и тестовые примеры. Не присваивать новый непрерывный seq, скрывая пробелы исходной последовательности: выпустить coverage_gap и сохранить исходный seq.

Для shell и кода внутри инструментов разделять заявленные цели и реально ограниченные/наблюдаемые эффекты. Кавычки, переменные, heredoc, alias, подстановка команд, кодирование, скрипты из файла и дочерние процессы делают простой regex неполным. Не запускать подозрительную команду для выяснения её смысла. Если цели неизвестны, `targets_complete=false` и передача на аудит.

Санитизация вывода не меняет оригинальные байты доказательства. Escape-последовательности и текст «новый system prompt» внутри лога не являются управляющими инструкциями. Не загружать исходные секреты в контекст модели; сначала выделить разрешённые метаданные локальным детерминированным кодом.
