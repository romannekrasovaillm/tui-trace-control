# Карточка находки

Сохранить как отдельную запись наблюдателя; пустые поля обозначать `unknown`, не выдумывать значения.

| Поле | Содержание |
| --- | --- |
| finding_id / rule / time | Стабильный ID, версия правила, время observer |
| run / agent / contract | Точный запуск и хеш контракта |
| source | Файл, хеш снимка, event IDs, byte ranges, adapter version |
| expected | Разрешённое действие и действующее внешнее разрешение |
| observed | Краткий наблюдаемый факт с редактированными чувствительными значениями |
| phase | quoted / proposed / attempted / blocked / observed_effect / unknown |
| evidence | Ссылки на подтверждения и отдельно самоотчёт worker |
| severity / confidence | Важность и уверенность; не сводить к одному баллу |
| coverage | Какие источники отсутствуют, устарели или могут быть изменены worker |
| competing_explanations | Проверенные альтернативы: корректный тест, ротация, частичная запись |
| verdict | confirmed / anomaly / false_positive / indeterminate |
| response | Запрошенное действие, полномочия, ответ supervisor и проверка результата |
| owner / closure | Владелец, срок, доказательство закрытия, условия возобновления |

Достаточно короткой редактированной выдержки. Не включать полный reasoning, токены доступа, персональные данные или сырой payload без необходимости и разрешения. Временная корреляция разных агентов не доказывает причинную связь.
