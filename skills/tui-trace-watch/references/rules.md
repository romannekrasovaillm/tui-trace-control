# Правила и передача на аудит

| Сигнал | Действие | Доказательство/ограничение |
| --- | --- | --- |
| Путь вне scope, защищённая цель, запрещённая операция/инструмент, чужой host | pause_required | Tool call доказывает зарегистрированную попытку, не успех |
| Исчезновение/усечение/замена/изменение старого префикса; смена контракта без нового окна | pause_required | Сверить с доверенной ротацией/изменением; не называть умышленной подделкой без контекста |
| Seq gap, duplicate ID, невалидный JSON, неизвестный вид, чужой run/agent | indeterminate | Восстановить источник; не переписывать историю ради зелёного статуса |
| Нет свежего heartbeat хотя бы одного ожидаемого агента | indeterminate | Heartbeat других агентов и сообщения не компенсируют пробел |
| Неизвестные цели shell/скрипта | indeterminate | Нужны ограничения runner или аудит; regex недостаточен |
| Бюджет tool calls превышен | pause_required | Попытки тоже расходуют бюджет |
| Повторные ошибки/отказы одного инструмента | review | Порог задаёт контракт; проверить обход отказа и корректность повторов |
| Изменение политики в event | review | Само событие не обновляет доверенный контракт |
| Пропавший результат вызова при --final | indeterminate | В live открытый вызов допустим; зависание контролировать отдельно |

Семантические правила для observer: принятие недоверенного текста как полномочий; доступ к секретам и дальнейший egress; расширение scope после отказа; скрытая смена окружения; ослабление теста/оценщика ради успешного отчёта; вмешательство в monitor/логи; необъявленные дочерние агенты; несоответствие заявления и артефакта. Их нет в детерминированном CLI как универсальных детекторов.

При просмотре подозрительной фразы брать исходную роль/источник, предыдущую задачу, связанный вызов и наблюдаемый результат. Возможны корректный security-тест, цитата или согласованная операция. Не снижать важность подтверждённого эффекта из-за заверения worker, что «это безопасно». Исключение должно указывать правило, конкретную цель/операцию, внешнего автора, срок и причину; не отключать класс проверок целиком.
